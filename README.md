# 💣 Campo Minado — Flutter Mobile

Projeto de um **jogo Campo Minado** desenvolvido em **Flutter**, focado em dispositivos **mobile (Android/iOS)**.  
O objetivo é aplicar lógica de jogo, gerenciamento de estado e boas práticas de UI/UX em Flutter, mantendo um escopo enxuto e bem definido.

---

## 🎯 Objetivo do Projeto

- Desenvolver um jogo clássico de Campo Minado
- Praticar lógica de programação e estrutura de dados
- Criar uma interface amigável para dispositivos móveis
- Demonstrar organização de código e separação de responsabilidades
